# Terraform Infrastructure

Terraform infrastructure-as-code lab for managing the home KVM/libvirt environment.

## Purpose

This project is part of my Cloud and DevOps learning journey.

The initial focus is on learning Terraform fundamentals and managing disposable infrastructure in the local KVM/libvirt environment before progressing to AWS.

## Planned Learning

- Terraform fundamentals
- Providers and resources
- Terraform state
- Variables and outputs
- Infrastructure lifecycle
- Infrastructure drift
- libvirt/KVM infrastructure
- Cloud-init
- Terraform and Ansible integration
- AWS infrastructure
